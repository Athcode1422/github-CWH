git init - To intialize git repository.
git status - To chech the status of folders and files whether they are untracked, in the staging area or not commited yet.
git add - This command is used to add the untracked files and folders to the staging area.
git commit -m "Message" - Used to push the files from satging area to git.
git log - Used to get the review of our commits done till the time.
git log --oneline - Used to get the log deatils in one line.
git config --global user.name "Atharv" - Used to set user name .
git config --global user.email "atharv@athcode.com" - Used to set email. 
.gitignore - In this file we add the directories which we dont want to commit to git 
.gitkeep - usually git dont track empty folders so if we want to track it we have to add .gitkeep file in that folders
git branch branch_name - Used to create a branch 
git branch - uSed to check In which branch we are currently 
git switch branch_name - Used to switch betweeen branches
git merge branch_name - Used to merge the branch with master branch
git branch -d branch_name - used to delete a branch
git switch -c branch_name - Used to create and switch into that branch
